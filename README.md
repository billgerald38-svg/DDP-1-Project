# DDP-1-Project - KTP Sensor Platform


What is KTP Sensor platform?
KTP sensor is a platform where user can photograph their KTP and choose sensitive fields that they want to sensor.
This is needed because when we want to apply to a job, organization, or any registration that require photo of KTP. We need to sensor some fields and add some information that this KTP are use for "applying a job" at this "date". This were needed to prevent private information leak and misuse of user KTP.
